Perception Evaluation Dashboard

From evaluator job to release verdict, on one dashboard.

The System In One Look

Four stages, one shared selection.

Everything downstream reads the run selection made on Overview. The selection travels through the URL (?mode=…&run_a=…), a browser cookie, and a server-side store — which is what makes every view shareable as a link.

STAGE 01AcquireDownload or Workflow page pulls evaluator results into a run folder under data/.
STAGE 02ProcessLocal eval produces Summary.csv / Score.csv; parquet build produces detection frames.
STAGE 03SelectOverview picks Baseline A (and Candidates B, C, …), sets label filters, mints the share link.
STAGE 04AnalyzeDetail pages, 3D viewers, TLR analysis, trend history, and PDF / specsheet exports.

The one rule that answers most questions

Always start on Overview. It is the only page that sets mode, runs and label filters, and the only one that seeds the share link / cookie / server-side memory that all other pages restore from. If a page says “Please load data from the Overview page first”, open Overview once so the URL contains run_a=…, then return.
